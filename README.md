# whatsapp-drive-sync

Sync WhatsApp group photos to a dated Google Drive folder on demand, for weekly print selection and a hallway display screen.

## איך זה עובד

יש כאן שני חלקים שרצים יחד, בתוך אותו תהליך אחד שאתה מפעיל על המחשב:

1. **מאזין ברקע** — מחובר לוואטסאפ שלך (כמו מכשיר מקושר) ותופס כל תמונה שנשלחת לקבוצות, שומר אותה מקומית עם שם השולח והזמן. זה קורה לבד, בלי שום פעולה מצדך.
2. **עמוד ווב מקומי** (`http://localhost:3000`) — שם אתה בוחר אילו קבוצות לכלול בסנכרון (או משתמש בבחירה האחרונה), ולוחץ "סנכרן עכשיו". זה לוקח את כל התמונות שנתפסו ועדיין לא סונכרנו, ומעלה אותן לדרייב.

כל תמונה מועלית לתיקייה בדרייב שנקראת לפי **תאריך היום** (למשל `2026-09-28`) — אם כבר יש תיקייה כזו מסנכרון קודם באותו יום, התמונות נוספות אליה. שם כל קובץ הוא **שם השולח** (+ שעה קטנה, רק כדי שתמונות מאותה מורה לא ידרסו זו את זו).

## התקנה

### 1. דרישות
- מותקן Node.js (גרסה 18 ומעלה) על המחשב שעליו זה ירוץ.

### 2. התקנת חבילות
```bash
npm install
```

### 3. הכנת גישה לגוגל דרייב (Service Account)
1. היכנס ל-[Google Cloud Console](https://console.cloud.google.com/) וצור פרויקט חדש (או השתמש בקיים).
2. הפעל (Enable) את **Google Drive API** עבור הפרויקט.
3. צור **Service Account** (תחת IAM & Admin → Service Accounts), וצור לו מפתח מסוג JSON — הקובץ יורד למחשב שלך.
4. שמור את קובץ ה-JSON בתיקיית הפרויקט (למשל בשם `service-account.json`) — **אל תעלה אותו ל-GitHub**, הוא כבר ב-`.gitignore`.
5. בדרייב שלך, צור תיקייה שתשמש "הורה" לכל תיקיות הסנכרון (למשל "תמונות מוואטסאפ"), ושתף אותה עם כתובת האימייל של ה-Service Account (נמצאת בתוך קובץ ה-JSON, שדה `client_email`) כ-**עורך (Editor)**.
6. קח את ה-ID של אותה תיקייה מתוך הכתובת שלה בדפדפן (החלק שאחרי `folders/`).

### 4. הגדרת משתני סביבה
```bash
cp .env.example .env
```
ואז ערוך את `.env`:
```
GOOGLE_SERVICE_ACCOUNT_KEY_FILE=./service-account.json
GOOGLE_DRIVE_PARENT_FOLDER_ID=<ה-ID מהשלב הקודם>
```

### 5. הרצה
```bash
npm start
```
בפעם הראשונה יופיע קוד QR בטרמינל — סרוק אותו מהטלפון (וואטסאפ → הגדרות → מכשירים מקושרים → קישור מכשיר). החיבור נשמר מקומית ולא תצטרך לסרוק שוב, כל עוד לא תמחק את תיקיית `data/`.

לאחר החיבור, פתח בדפדפן:
```
http://localhost:3000
```
שם תוכל לבחור קבוצות ולסנכרן.

## הרצה קבועה ברקע

כדי שהמאזין יתפוס תמונות גם כשאתה לא ליד המחשב, השאר את התהליך פעיל (חלון טרמינל פתוח), או הרץ אותו כשירות רקע עם כלי כמו [pm2](https://pm2.keymetrics.io/):
```bash
npm install -g pm2
pm2 start src/index.js --name whatsapp-drive-sync
```
