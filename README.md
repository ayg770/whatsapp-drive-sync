# whatsapp-drive-sync

A shared link: whoever opens it links their own WhatsApp for a moment, picks which groups to pull from, and their recent group photos get uploaded straight into one shared Google Drive folder — dated by day.

## איך זה עובד

זה דף ווב אחד, פתוח לכמה אנשים מסוימים בלבד (בלי סיסמה — מיועד לקבוצה קטנה וסגורה שיש להם את הלינק). כל מי שנכנס אליו:

1. רואה קוד QR **בדף עצמו**, וסורק אותו עם וואטסאפ שלו (וואטסאפ → הגדרות → מכשירים מקושרים → קישור מכשיר) — בדיוק כמו וואטסאפ Web.
2. ברגע שהתחבר, רואה את רשימת הקבוצות **שהוא עצמו חבר בהן**, ובוחר אילו לכלול (עם זיכרון של הבחירה האחרונה בדפדפן שלו, כדי לא לבחור מחדש כל פעם).
3. לוחץ "העלה לדרייב" — המערכת שולפת מההיסטוריה הקרובה (מהטלפון שלו, שכבר קיבל את ההודעות כרגיל) את התמונות מהקבוצות שנבחרו, ומעלה אותן.
4. מיד אחרי ההעלאה, **הוואטסאפ שלו מתנתק אוטומטית** מהמערכת — זה חיבור חד-פעמי, לא חיבור קבוע שנשאר תלוי.

כל התמונות (מכל מי שמסנכרן, מכל קבוצה) עולות לאותה **תיקיית דרייב אחת קבועה** שהוגדרה מראש (למשל תיקיית בית הספר), לתת-תיקייה לפי **תאריך היום** — אם כבר יש תיקייה כזו מסנכרון קודם באותו יום, התמונות מצטרפות אליה. שם כל קובץ הוא **שם השולח** (+ שעה קטנה, רק כדי שתמונות מאותה מורה לא ידרסו זו את זו).

כדי שתמונה לא תועלה פעמיים אם שני אנשים שונים מסנכרנים את אותה קבוצה, המערכת זוכרת (בצד השרת, לא תלוי במשתמש) את הזמן האחרון שסונכרן לכל קבוצה, ומעלה רק תמונות חדשות יותר מזה.

**חשוב להבין:** מכיוון שכל אחד מקשר את הוואטסאפ *שלו*, מי שרוצה לסנכרן קבוצה מסוימת חייב להיות בעצמו חבר בקבוצה הזו בוואטסאפ.

## התקנה

### 1. דרישות
- מותקן Node.js (גרסה 18 ומעלה) על המכונה/שרת שעליו זה ירוץ.

### 2. התקנת חבילות
```bash
npm install
```

### 3. הכנת גישה לגוגל דרייב (Service Account)
1. היכנס ל-[Google Cloud Console](https://console.cloud.google.com/) וצור פרויקט חדש (או השתמש בקיים) — מומלץ עם חשבון הגוגל של בית הספר.
2. הפעל (Enable) את **Google Drive API** עבור הפרויקט.
3. צור **Service Account** (תחת IAM & Admin → Service Accounts), וצור לו מפתח מסוג JSON — הקובץ יורד למחשב שלך.
4. שמור את קובץ ה-JSON בתיקיית הפרויקט (למשל בשם `service-account.json`) — **אל תעלה אותו ל-GitHub**, הוא כבר ב-`.gitignore`.
5. בדרייב של בית הספר, צור את תיקיית היעד הקבועה (למשל "תמונות מוואטסאפ"), ושתף אותה עם כתובת האימייל של ה-Service Account (נמצאת בתוך קובץ ה-JSON, שדה `client_email`) כ-**עורך (Editor)**.
6. קח את ה-ID של אותה תיקייה מתוך הכתובת שלה בדפדפן (החלק שאחרי `folders/`).

### 4. הגדרת משתני סביבה
```bash
cp .env.example .env
```
ואז ערוך את `.env`:
```
GOOGLE_SERVICE_ACCOUNT_KEY_FILE=./service-account.json
GOOGLE_DRIVE_PARENT_FOLDER_ID=<ה-ID מהשלב הקודם>
```

### 5. הרצה
```bash
npm start
```
ואז פתח בדפדפן:
```
http://localhost:3000
```

## הפצה לכמה אנשים (הלינק המשותף)

כדי שכל האנשים (אתה, עורך העיתון, ועוד 1-2 נוספים) יוכלו להיכנס לאותו לינק ולסנכרן כל אחד מהוואטסאפ שלו, הדף הזה צריך לרוץ על **שרת נגיש דרך האינטרנט**, לא רק על `localhost` של מחשב אחד — כי הוא לא צריך לרוץ כל הזמן ברקע (רק כשמישהו בפועל נכנס לסנכרן), הוא מתאים היטב לאירוח קטן וחינמי (למשל שרת חינמי תמידי ב-Oracle Cloud Free Tier, או שירות כמו Fly.io/Render). אחרי שיוקם, כל אחד פשוט נכנס לאותו כתובת URL מהדפדפן שלו (במחשב או בטלפון) ומבצע את התהליך בעצמו.

אם תרצה, אפשר להמשיך מכאן ולהקים את זה על שרת כזה.
